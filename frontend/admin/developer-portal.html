QCMS Developer API Overview

v1.0 Stable

Welcome to the QCMS (Quality & Continuous Improvement Management System) Integration API. Our API allows external applications (such as Ideation Tools, ERP systems, CRMs, and custom workplace software) to securely sync continuous improvement ideas, Kaizen projects, and quality records into QCMS.

Secure Authentication

Bearer token authentication hashed using SHA-256 with per-organization isolation.

High Velocity

Built-in rate limiting (100 req/min), sliding window protection, and sub-50ms latency.

Modular Architecture

Future-proof REST design for seamless expansion to Users, Projects, and Webhooks.

2. Authentication

All requests to the QCMS Integration API must include a valid Organization API key passed as a Bearer token in the Authorization HTTP request header.

HTTP Header Format 
Authorization: Bearer qcms_live_83hd92jd93jd83jd93jd93jd
Security Best Practices:
  • Never expose secret API keys in client-side applications or public code repositories.
  • Always transmit requests over HTTPS.
  • Regenerate keys periodically or immediately if compromised under Settings → Integrations.

3. Base URL

The QCMS Integration API is served over HTTPS. Use the following base URLs depending on your environment:

4. API Key Lifecycle Management

Organization Administrators can manage API keys in QCMS via Settings → Integrations:

  • Generate API Key: Creates a new live secret key (format qcms_live_...).
  • Regenerate Key: Invalidates the current key and issues a new key immediately.
  • Enable/Disable Key: Temporarily pause API traffic without deleting credentials.
  • Delete Key: Permanently revokes access.

5. Quick Start Guide

1
Generate API Key in QCMS Platform (Settings → Integrations).
2
Copy Secret Token (e.g. qcms_live_TvvFkQ6zRRI6YIAUAA4CL...).
3
Make HTTP POST Request to /api/v1/integrations/ideas with JSON body.
4
Receive 201 Created response confirming idea storage.

6. Endpoint: Import Approved Idea

POST /api/v1/integrations/ideas

Pushes an approved continuous improvement idea from external tools (Ideation Tool, ERP) into the QCMS database.

Request Body Fields
Field NameTypeRequiredDescription
ideaCode string Required Unique identifier code for the idea (e.g., IDA-2026-006). Used for duplicate checking.
title string Required Short title describing the continuous improvement initiative.
presentSituation string Optional Current problem statement or defect situation description.
proposedSolution string Optional Proposed corrective action or solution.
category string Optional Category (Quality, Cost, Delivery, Safety, Morale, Environment, Productivity). Default: Quality.
department string Optional Target department name (e.g. Production).
submittedBy string Optional Primary submitter full name.
coSuggesters array[string] Optional List of co-submitter names (e.g. ["Smith", "David"]).
tangibleBenefit number Optional Estimated financial savings in currency.
intangibleBenefit string Optional Qualitative benefit description (e.g. "Customer Satisfaction").
investmentRequired number Optional Required capital expenditure.
implementationTime string Optional Estimated implementation duration (e.g. 8 Weeks).
impactLevel string Optional Impact level (Low, Medium, High). Default: Medium.
status string Optional The current status of the idea. Default: Approved.

9. Error Codes & Specifications

The API uses standard HTTP response status codes to indicate request outcome:

401 Unauthorized Missing, Invalid, or Disabled API Key 
{"error": "Unauthorized", "message": "Invalid or disabled API Key."}
409 Conflict Duplicate Idea Code 
{"message": "Idea already imported."}
429 Rate Limit Rate Limit Exceeded (100 req/min) 
{"error": "Too Many Requests", "message": "Rate limit exceeded. Maximum 100 requests per minute allowed."}

14. Rate Limits

To ensure system stability, requests are limited to 100 requests per minute per organization. Exceeding this limit triggers an immediate 429 Too Many Requests HTTP response.
